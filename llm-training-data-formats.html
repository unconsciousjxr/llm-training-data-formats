01

SFT · 有监督微调

提供问题与理想回答，教模型按指令生成目标内容。

ShareGPT

多轮对话 · 通用

以角色和值组成对话轮次；LLaMA-Factory、Axolotl 等框架常见。

JSONL
{"conversations":[{"from":"human","value":"你好"},{"from":"gpt","value":"你好！有什么可以帮你的？"}]}
system 提示通常需要作为一轮消息手动加入。

Alpaca

单轮指令 · 简洁

拆为 instruction、可选 input 和目标 output，适合简单问答与指令任务。

JSON
{"instruction":"翻译成英文","input":"今天天气真好","output":"The weather is really nice today."}
没有额外输入时，input 字段可以省略。

OpenAI Chat

多轮 · 含 system · 消息结构

使用 role/content 消息列表，结构接近 Chat API，适合 OpenAI 微调生态及新式框架。

JSONL
{"messages":[{"role":"system","content":"你是助手"},{"role":"user","content":"你好"},{"role":"assistant","content":"你好！"}]}

02

Pre-training · 预训练

从大量文本中学习语言规律与知识。

纯文本 Raw Text

大规模 · 简单

不做复杂结构化，常按文档或 token 序列组织。

TXT
今天天气很好，适合出去散步。春天来了，万物复苏……

常见为 .txt 或逐行文档，训练时可按 token 量拼接（packing）。

JSONL 文档

保留边界与元信息

每行一篇文档，可附来源、编号等字段，便于追踪和筛选。

JSONL
{"text":"文档内容……","source":"wiki","id":"doc_001"}
{"text":"另一篇文档……","source":"book","id":"doc_002"}
03

DPO / RLHF · 偏好对齐

同一提示下给出更好与较差的回答，让模型学习偏好。

标准 DPO

prompt + chosen / rejected

chosen 是偏好的回答，rejected 是不偏好的回答。

JSONL
{"prompt":"如何学习编程？","chosen":"建议从 Python 开始……","rejected":"随便学，无所谓。"}
{"prompt":"什么是机器学习？","chosen":"机器学习是……","rejected":"不知道。"}
也可用多轮 messages 表示 prompt，再分别提供 chosen 与 rejected。
04

KTO / ORPO · 偏好格式变体

按训练方法选择单条反馈标签或成对偏好样本。

KTO

单条反馈 · 无需配对
JSONL
{"prompt":"…","completion":"…","label":true}
{"prompt":"…","completion":"…","label":false}

label 表示回答是期望还是不期望。

ORPO

SFT + 偏好联合训练
JSONL
{"prompt":"…","chosen":"…","rejected":"…"}

用成对偏好字段表达优选与非优选回答。

05

Tool Calling · 工具调用

训练模型发起 API 调用、读取工具结果，再组织自然语言答复。

消息序列 + tool_calls

请求 → 工具结果 → 回复
JSONL
{"messages":[
 {"role":"user","content":"北京今天天气怎么样？"},
 {"role":"assistant","tool_calls":[{"id":"call_1","type":"function","function":{"name":"get_weather","arguments":"{\"city\":\"北京\"}"}}]},
 {"role":"tool","tool_call_id":"call_1","content":"{\"temperature\":25}"},
 {"role":"assistant","content":"北京今天25度，晴天。"}
]}

Multimodal · 多模态

在对话中引用图像等媒体，并保留文件路径或媒体载荷。

LLaVA 图文格式

图像 + 对话
JSON
{"id":"001","image":"images/cat.jpg","conversations":[
 {"from":"human","value":"<image>\n这是什么动物？"},
 {"from":"gpt","value":"这是一只猫。"}
]}
07

快速选择

先按训练目标选结构，再核对目标框架的数据字段要求。

通用对话微调 → ShareGPT多轮轮次直观，常见开源框架适用。
简单指令任务 → Alpaca字段少，适合 instruction/input/output。
OpenAI 生态 → OpenAI Chat消息结构统一，支持 system 与多轮。
偏好对齐 → DPO用 chosen / rejected 表达回答偏好。
大规模语言学习 → 预训练文本原始文本或带元信息的 JSONL 文档。
工具调用 → Chat + tool_calls串起模型调用、工具结果和最终回复。
图文任务 → LLaVA用图像引用与对话轮次组合样本。
通用起点：ShareGPT 或 OpenAI Chat 通常覆盖单轮与多轮对话；工具调用或多模态任务需按框架要求补充相应字段与媒体数据。
